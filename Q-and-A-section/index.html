What is the main purpose to learn HTML, CSS and JavaScript?

We learn HTML, CSS, and JavaScript (JS) because they are the three fundamental pillars that power the entire world wide web. Every single website you visit is ultimately built, styled, and operated using these three technologies, regardless of how complex the backend server is.

What is backend in web applications?

The backend of a web application is the server-side infrastructure that powers everything happening behind the scenes. While users directly interact with the user interface (the frontend), the backend manages the core business logic, data storage, user authentication, and server calculations required to make the application function correctly and securely.

what is the difference between the library and frameworks?

The core difference is who controls the flow of execution. With a library, your code calls the pre-written code whenever you need it. With a framework, the framework dictates the overall architecture, handles the background execution, and calls your custom code when necessary.
